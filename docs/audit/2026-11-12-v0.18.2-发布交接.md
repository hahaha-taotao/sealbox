## 卡在哪

本地没有任何 GitHub 凭据（无 credential helper、无 `GH_TOKEN`），`git push` 报
`could not read Username for 'https://github.com'`。按设计，推送必须走 sealbox MCP 的
`git` 工具，由金库里的 Token 完成。

MCP 服务端本身正常（`127.0.0.1:17891` 在监听，`initialize` 无 Token 返回 401）。
问题在客户端：本次会话的 MCP 连接建立在会话票据过期之前，失效后不会自动重连，
所有 MCP 调用都返回 `MCP session revoked or expired; initialize again`。

这与本次改动引入的会话过期机制直接相关——改动前会话永不过期，不会有这个现象。
