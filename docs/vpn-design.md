# Sealbox VPN 工作台：开发设计

## 目标和范围

桌面侧栏增加「VPN」。日常从访问入口进入；在入口设置里选择 VPN 客户端及配置、绑定一个或多个密码库 VPN 账号。首版是连接编排，不自带 VPN 协议或驱动。Windows 优先；Linux/Android 必须继续正常读写 VPN 类型的密码库条目，未实现的平台连接和启动功能明确标为不可用。不改发布流程或版本号，不执行单端构建。

## 密码库和设置

- 密码库新增 `vpn` 类型：标题、账号、密码、可选 HTTPS 登录网站和备注。密码复用现有加密、解锁、编辑和删除路径。桌面与移动端的类型、标签和兼容处理一起补齐，校验旧库、备份/恢复、同步和已有其他类型；不要为了 VPN 改变其他凭据的自动填表行为。
- 「VPN → 入口设置」：目标（网页或本机应用）、VPN 连接（客户端与明确的网关/配置）、登录方式、已绑定账号。绑定选择器只列未删除的 VPN 条目，支持按标题或账号搜索、多选、移除以及设置默认；也支持「每次询问」。一个账号可用于多个入口。
- 入口可以引用复用的连接配置，但账号列表、默认账号、自动提交是**按入口**设置。VPN 配置只持久化引用 ID 和非密码参数；不得复制密码、验证码、会话 Cookie 或 Clash 控制密钥到明文设置、日志或调试输出。读取、保存和访问时由后端检查 ID、类型、状态、默认项是否在列表中。账号改名或改密码后使用最新条目。失效引用可见且可移除，默认失效不自动递补。未绑定账号也可使用纯客户端登录或现有网络。

## 访问行为

1. 默认访问：如果目标已可达且用户没有指定切换账号，可直接打开（不要把「可达」显示成「以某账号登录」）。只有一个账号可直接作为本次选择；多个账号用有效默认值，否则弹出选择。访问按钮旁提供「使用其他账号」。明确切换身份时不能根据可达性假装已经切换；复用现有会话之前应说明它可能属于前一个账号。禁止尝试列表里的其他账号，禁止自动断开既有 VPN。
2. 针对选中的连接发起访问；有可靠的状态或目标探测则等待就绪再打开，有超时和取消。不能可靠判断时给出「登录完成后打开」的显式退路，不把进程存在或代理探测等同于目标就绪。切换入口或取消后，不应有旧任务继续打开目标。
3. 网页密码填充走现有配对浏览器扩展和本机授权链路，按用户发起的单次访问授予短时、一次性的填充权限。将权限限制到**所选账号、具体浏览器标签页和当前顶层页面的精确 HTTPS origin**；不同子域和不同端口不匹配，跳转到不同 origin 或换页时拒绝，不能复用。密码库锁定、缺少扩展、不匹配、未知页面均回退到原网页登录；不要让 VPN 账号混入普通网站自动匹配、原生窗口模拟输入或 MCP 凭据途径。不记录密码、不额外暴露通用解密或填充接口。
4. 默认仅填充；自动提交是可单独开启的设置。仅在已确认的页面适配器可肯定识别普通账号密码流程时自动提交一次。不确定是否有验证码时只填不提交；同页验证码由用户填写并提交，提交后出现 MFA 则继续等待用户处理。不要猜测验证码、静默重试或把网页登录当成 VPN 已连通。若无法安全地把填充授权绑定到正确标签页，首版降级为用户显式在官方网页触发填表/手动登录，不做缺保护的自动提交，并如实说明限制。

## 客户端优先级

| 客户端 | 首版行为 |
|---|---|
| aTrust、EasyConnect | 唤起安装的官方客户端；部署有受支持的浏览器登录入口时才走网页填表。原生窗口由客户端或用户处理。 |
| OpenVPN Connect | 选择已导入的配置；按官方连接快捷方式发起，缺支持时唤起客户端。保留官方认证。 |
| Clash | 复用已有代理/规则，可按需唤起已安装客户端；不默认修改系统代理、TUN 或全局策略。 |
| Tailscale | 最低优先级，只做已有连接的访问或以后接入，不阻塞首版。 |

本机启动用固定的客户端适配器、结构化参数、本机明确选择的目标或受限的 URL 类型，不执行任意 shell 字符串。没有工具、没有客户端、配置不存在时给出可理解提示。

## 验收

- 新增/编辑 VPN 凭据，旧密码库仍能使用；移动端显示该类型，旧类型行为不变。
- 一个入口绑定两个账号并保存重开；有效默认可用，「每次询问」可选择，改名可见，删除默认后不误用另一个账号。
- 锁库、撤销或过期授权、错误网站/标签页、非 VPN 凭据、已删除凭据、同页验证码、需要二次认证、错误密码时不错误发放、提交或重试。
- 客户端缺失、连通超时、取消、已可达、登录后的继续访问，均有明确反馈；无真实企业环境则做模拟/单元测试并明确列出待真机验证项。
