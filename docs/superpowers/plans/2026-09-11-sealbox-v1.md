# Sealbox 印盒 v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在 Windows 上交付本地凭据金库：主密码/Hello 解锁、三类条目、复制+快捷键、加密备份；明文不进前端、不进审计。

**Architecture:** Tauri 2 单进程。Vue 3 只拿元数据；Rust 持有 DEK 会话、SQLite 密文、剪贴板超时、备份。本机 MCP 监听 loopback，GitHub 只读工具由单一 `GithubMcpPolicy.enabled` 开关控制；Rust 固定访问 `api.github.com`，模型通过凭据 ID 选择活动 Token。

**Tech Stack:** Tauri 2.11、Vue 3 + TypeScript + Vite、rusqlite、argon2、aes-gcm、zeroize、Credential Manager、WinRT UserConsentVerifier。

**Spec:** `docs/superpowers/specs/2026-09-11-local-credential-vault-design.md`

Integration tests import `sealbox_lib` (Windows lib name).

## Tasks

1. Scaffold Tauri 2 + Vue 3, identity Sealbox / `com.sealbox.app`
2. Crypto primitives TDD (Argon2id, AES-256-GCM, wrap/unwrap)
3. SQLite schema + VaultService CRUD (no blobs in DTO; search excludes notes)
4. Session lock + clipboard timed clear
5. Tauri commands + Vue typed API
6. Visual shell (Sigil-like CSS, our IA)
7. Folders, tags, trash, audit, home, settings
8. Windows Hello
9. Tray, idle lock, quick search window
10. `.svbak` backup export/import with re-encrypt on merge
11. TOTP + password generator + polish

See conversation + spec for exact APIs. Execute inline, TDD for Rust core, commit after each task.
