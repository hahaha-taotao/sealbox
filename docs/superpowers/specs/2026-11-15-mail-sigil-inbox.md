# 邮箱主流程优化（对照 Sigil）

参考：https://sigil.ruoyi.plus/features/mail.html

## 本轮落地

- 桌面默认进入全部收件箱，跨可用账号聚合 INBOX，按邮件日期倒序排列。
- 聚合行携带 entryId、folder、uid、accountEmail；选择、高亮、去重、正文与附件下载均使用完整来源，UID 不再被当作全局标识。
- 每个账号维护独立分页游标，加载更早时合并去重；单账号失败保留其余账号结果并提示。
- 单账号文件夹仍按 UID 倒序分页；全局未读数只用于总角标，文件夹数字来自当前账号。
- 正文成功后才在界面记已读，附件独立请求，不阻塞正文显示。
- 桌面阅读器增加上一封/下一封；中等宽度保留账号侧栏，并在列表与正文间切换。
- 本地缓存不等同离线；正文预热事件不冒充列表同步。
- 手机同步优化账号/文件夹/搜索布局、正文导航、附件加载、切换竞态与未读口径。

## 保持的能力边界

本轮沿用当前只读邮件后端，未引入 SMTP、发信、回复、删除、远端标记、OAuth、定时发送、签名和 MCP 写操作。它们在 Sigil 中存在，但不是本次已完成能力。
