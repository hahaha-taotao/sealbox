## 最终目标

将 GitHub MCP 简化为单一能力开关：

- `enabled=true`：所有活动的 GitHub API Token 都可用，六个 GitHub 业务工具全部可用；
- `enabled=false`：六个业务工具全部从 `tools/list` 隐藏，并拒绝直接调用；
- 不再有 Token 选择器、scope 选择、仓库白名单或 legacy 通用工具开关；
- 模型通过 Token 元数据 ID 选择要使用的 GitHub Token。

固定安全边界保持不变：只访问 `https://api.github.com:443`、固定 GET、固定 Header、无任意 URL/Header/Body、不跟随重定向、响应结构化过滤、Token 不返回模型。

## 1. Token 选择方式

由于不再由前端选择固定 Token，新增一个只读辅助工具：

- `github_list_credentials`
  - 只返回活动 GitHub API Token 的 `id/title/account`；
  - 不返回 Token、Authorization 或其他秘密；
  - 只在 GitHub MCP 启用时暴露；
  - 它是凭据发现工具，不增加 GitHub 数据访问能力。

六个业务工具都新增必填 `credential_id` 参数：

- `github_get_authenticated_user`
- `github_list_repositories`
- `github_get_repository`
- `github_get_file`
- `github_list_issues`
- `github_list_pull_requests`

调用时由模型先调用 `github_list_credentials`，再把选中的 ID 传给业务工具。后端每次都重新验证该 ID 对应的是活动的 `ApiToken`，且 `service=github`。

## 2. 后端策略简化

修改 `src-tauri/src/github_mcp.rs`：

- `GithubMcpPolicy` 只保留 `enabled: bool`；
- 删除 `credential_id`、`GithubScope`、`scopes`、`allowed_repositories` 及其规范化逻辑；
- `enabled=true` 时不再要求预选 Token，只要求金库已解锁；
- `prepare` 从工具参数读取 `credential_id`，校验活动条目、payload 类型和 GitHub service，并返回对应 Token；
- 保留 owner/repo 格式校验、路径穿越防护、ref 校验、URL 编码、分页限制和固定 API host 检查；
- 删除仓库白名单过滤和 `ensure_allowed_repository`；
- `github_list_repositories` 直接返回经过 DTO 过滤和数量限制的结果，不再按本地白名单过滤；
- 工具描述删除 scope/白名单文案；不再返回 `requiredScopes` 或 `requiresRepository` 元数据；
- 新增 `github_list_credentials` 的结构化元数据返回；
- 审计保留 operation、decision、reason、credential fingerprint、repo/path/ref、status、count，不再记录 scope；
- “能力未启用”使用稳定的 `disabled` 拒绝原因。

### 旧策略迁移

旧的加密 `github_mcp_policy` 可能包含 `enabled`、`credential_id`、`scopes`、`allowed_repositories`：

- 读取旧结构时只保留 `enabled`；
- 旧数据中如果存在 scope/仓库白名单字段，迁移后将 `enabled` 设为 `false`，避免旧的局部权限意外扩大为全部 Token/全部仓库；
- 用户在新界面明确启用后才生效；
- 新保存只写 `{ enabled }`，清除旧字段。

## 3. MCP 工具目录和 legacy 能力

修改 `src-tauri/src/mcp.rs`：

- `tools/list` 仅在 GitHub MCP 启用且金库解锁时暴露：
  - `github_list_credentials`
  - 六个 GitHub 业务工具；
- 停用时工具完全不出现在 `tools/list`；
- 旧客户端即使直接调用缓存的 GitHub 工具名，也只得到 `disabled` 拒绝，不发网络；
- 删除 `list_credentials`、`http_request`、`copy_secret` 的 MCP 暴露、legacy 开关和相关分支；
- `ToolInfo` 删除 `required_scopes`/`requires_repository`；
- `McpStatus` 删除 `legacy_tools_enabled`；
- 删除 `mcp_legacy_tools_set`、`mcp_http_logs` 的前端契约和 Tauri 注册；
- MCP 服务仍按现有逻辑自动启动，页面只显示运行状态，不再提供服务启动/停止按钮；这避免影响助手和浏览器填表。

## 4. 助手契约

修改 `src-tauri/src/assistant.rs` 和 `src/lib/tauri.ts`：

- 删除 `AssistantChatRequest.enable_tools`；
- 删除助手页面“启用只读工具”复选框；
- 助手直接使用当前 MCP `tools/list`：启用时自动发现 GitHub 工具，停用时发现不到；
- `AssistantToolSummary` 删除 scope/仓库字段；
- 保留只读、低风险、`github_` 前缀过滤；
- 保留对模型主动调用未暴露工具的拒绝逻辑。

## 5. Tauri 和前端类型

修改 `src-tauri/src/commands.rs`、`src-tauri/src/lib.rs`、`src/lib/tauri.ts`：

- `GithubMcpPolicy` 前后端同步为 `{ enabled }`；
- 删除 `github_mcp_credentials` 的前端选择用途；凭据发现改由 MCP 辅助工具完成；
- 保留 `github_mcp_policy_get/set`，保存命令只处理启用/停用；
- 保留 `mcp_status`/`mcp_tools`、MCP Token 轮换和配置复制；
- 移除前端 API 的 `mcpStart`、`mcpStop`、`mcpLegacyToolsSet`、`mcpHttpLogs`；后端自动启动函数暂不删除，以保持现有生命周期兼容；
- `McpToolInfo`/`AssistantToolSummary` 删除 scope/仓库字段；
- `assistantChat` 请求删除 `enableTools`。

## 6. App.vue 界面

MCP 页面最终只保留：

- 本机 MCP 服务运行状态和端口的只读展示；
- MCP Token/配置片段显示、复制、轮换；
- 一个“启用 GitHub MCP / 停用 GitHub MCP”按钮；
- 六个 GitHub 业务工具的只读列表；
- 可选显示“模型可先调用 github_list_credentials 选择 Token”。

删除：

- GitHub Token 下拉选择器；
- scope checkbox；
- 仓库白名单输入、添加、chip、删除；
- legacy 通用工具开关；
- `http_request` 日志卡片；
- MCP 服务启动/停止按钮；
- 助手页独立工具启用 checkbox。

启用时只提交 `{ enabled: true }`；停用时只提交 `{ enabled: false }`。Token 选择完全由 MCP 工具参数完成。

## 7. 样式与文档

删除 scope、仓库、legacy、HTTP 日志专用 CSS，保留 MCP 状态、卡片、工具列表和只读标签样式。

更新 README、设计规格和旧计划文档：

- 说明只有一个 GitHub MCP 启用/停用开关；
- 说明所有活动 GitHub API Token 都可用，模型通过 `github_list_credentials` 选择 ID；
- 删除 Token 选择器、scope、仓库白名单、legacy 通用工具和助手独立开关说明；

## 8. 测试与验证

新增/调整测试：

- 默认策略只含 `enabled=false`；旧策略含旧字段时迁移为关闭；
- 启用/停用只验证一个开关；
- `github_list_credentials` 只返回活动 GitHub Token 元数据，不返回 Token；
- 六个业务工具缺少/错误/回收站 `credential_id` 时拒绝；
- 停用或锁定时 7 个工具都不出现在 `tools/list`，直接调用均拒绝；
- 启用时 7 个工具全部出现，业务工具 schema 都要求 `credential_id`；
- 合法 owner/repo 不再因本地白名单拒绝，非法路径和 URL 注入仍拒绝；
- 固定 API host、GET、响应 DTO、Issue/PR 过滤、Token 脱敏和审计测试继续保留；
- 助手解析无 scope/仓库字段的工具目录，并在停用时不调用 GitHub 工具；
- 运行：
  - `cargo test --manifest-path src-tauri/Cargo.toml`
  - `npm run build`
  - `node --test extension/fill-logic.test.js`
  - 变更 Rust 文件 `rustfmt --check`
  - `git diff --check`

不改变浏览器填表、普通凭据 CRUD、MCP/填表 Token 生命周期和自动启动服务行为。
